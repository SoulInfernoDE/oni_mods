--> Did you ever wanted to turn off the annoying "mouse hover" sound?

Now you can.

If you have a large base and the mouse hover sound goes "clickclicklick....click..click.clickclickclick..." you likely want to disable that after hundreds of hours gameplay.
This mod is intended to later enable some kind of sound switching or disabling abilities.


In this version it just "removes" the mouseover sound effect.


I may plan to include options for transfer that sound to the select buildings sound - because i think it makes it less noisy.



Please don't reuse this in any mods without pointing to this original repo.
